# Окно — семейный VPN в одну кнопку

Приложение для Android, iPhone, Windows и macOS: открыл, нажал кнопку, работает.
Настройки сервера зашиты в сборку и обновляются сами — пользователю ничего вводить не нужно.

## Основано на Hiddify

Этот репозиторий — форк [hiddify/hiddify-app](https://github.com/hiddify/hiddify-app)
(Flutter + sing-box). Лицензия — [Hiddify Extended GPL v3](LICENSE.md), все условия сохранены:
проект публичный, некоммерческий, релизы собираются только через GitHub Actions.

### Что изменено относительно Hiddify

- Название, иконка, идентификаторы пакетов (`app.okno.family`).
- Зашитая ссылка подписки (`--dart-define subscription_url=…`, в CI — переменная репозитория `SUBSCRIPTION_URL`),
  профиль подтягивается сам при запуске и обновляется каждые 6 часов (`lib/features/family/`).
- Без экрана приветствия: регион RU и русский язык выставляются автоматически.
- Убраны нижнее меню, боковая панель, кнопка «добавить профиль» и быстрые настройки — остался один экран с кнопкой.
  Настройки доступны долгим нажатием на заголовок.
- Экран «нет связи с сервером» с кнопкой «Повторить», если подписка не загрузилась при первом запуске.
- CI: артефакты `Okno-*`, подпись только при наличии секретов, выгрузка в сторонние репозитории убрана.

Полный список изменений — в истории коммитов.
