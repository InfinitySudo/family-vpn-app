Телефон Android

Samsung, Xiaomi, Honor и другие
  1. Нажми синюю кнопку — файл скачается.
  2. Открой его. Если телефон спросит — разреши установку.
  3. Открой «Окно», нажми большую кнопку. Готово.

iPhone и iPad

Apple iOS
  1. Установи из App Store бесплатное приложение TestFlight (ссылка ниже).
  2. Вернись сюда и нажми «Получить Окно» — откроется TestFlight, нажми Установить.
  3. Открой «Окно», нажми большую кнопку. Готово.
Получить Окно
Сначала нужен TestFlight из App Store. Пишет «недоступно»? Напиши Артёму свою почту Apple ID — пришлёт приглашение.

Компьютер Windows

Ноутбук или ПК
  1. Нажми кнопку — скачается файл установки.
  2. Открой его. Синее окно? «Подробнее» → «Выполнить в любом случае».
  3. Открой «Окно», нажми большую кнопку.
Скачать для Windows

Компьютер Mac

MacBook, iMac
  1. Нажми кнопку, открой файл, перетащи «Окно» в «Программы».
  2. Открой «Окно». Пишет «повреждено»? Позвони Артёму, это одна команда.
  3. Нажми большую кнопку.
Скачать для Mac

Как пользоваться

Открыл «Окно», нажал большую круглую кнопку. Стала зелёной — работает. Нажал ещё раз — выключилось. Больше ничего.

Ничего настраивать не нужно — всё уже внутри. Кнопки всегда скачивают последнюю версию.
